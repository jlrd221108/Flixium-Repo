# Flixium branding

Created with the built-in image generation tool from the supplied Flixium logo.
Transparent PNGs preserve the generated alpha channel; production assets are sized for Kodi.

Prompt set:
- Wordmark: extract the full silver/cyan three-bar emblem and exact FLIXIUM lettering; remove the textured background and navigation strip; true transparency.
- Emblem: isolate the three silver/cyan diagonal bars; no lettering; true transparency.
- Skin icon: centered Flixium emblem and FLIXIUM lettering on charcoal texture, generous safe margins.
- Helper icon: matching emblem, cyan cog badge, FLIXIUM HELPER lettering on charcoal.
- Fanart: widescreen charcoal texture and subtle cyan glow, centered horizontal wordmark, no navigation or tagline.

Files:
- flixium-wordmark.png: transparent master wordmark.
- flixium-emblem.png: transparent square emblem.
- flixium-icon-256.png / flixium-icon-512.png: add-on icons.
- flixium-helper-icon.png: companion icon.
- flixium-fanart.jpg: 1920x1080 fanart.

Production: extras/flixium-logo.png, resources/icon.png, resources/fanart.jpg, and the helper resources/icon.png.
