# Security policy

Please report suspected vulnerabilities privately using [GitHub's security reporting](https://github.com/jlrd221108/Flixium-Repo/security/advisories/new), rather than publishing exploit details in an issue. Include the affected package/version and steps to reproduce. Do not send passwords, access tokens or private media URLs.

Only the current Kodi 21 release channel is maintained here. Keep HTTPS and certificate verification enabled. SHA-256 hashes detect corruption or unexpected package content; they do not replace trust in the repository publisher or provide a separate signing identity.
